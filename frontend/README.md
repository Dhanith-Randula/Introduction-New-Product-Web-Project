# 💻 Frontend - Introduction to New Products Platform

The client-side single page application (SPA) for the Introduction to New Products platform, built with **React 18**, **React Router v6**, **Bootstrap 5**, and **Axios**.

---

## 🛠️ Features

- **Dynamic Showcase**: Modern hero landing page with featured items.
- **Product Catalog & Category Filtering**: Browse and filter products seamlessly.
- **Real-Time Search**: Search through products and categories.
- **Management Dashboard**: Add products with multiple image attachments, edit existing products, and delete items.
- **User Authentication**: Login & Sign Up workflows connected to the backend API.
- **EmailJS Contact Support**: Working contact form sending inquiries via EmailJS.

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Verify Backend
Ensure the backend server is running on `http://localhost:8070` before launching the frontend.

### 3. Run Development Server
```bash
npm start
```
Open [http://localhost:3000](http://localhost:3000) to view the application in the browser.

---

## 📦 Build for Production

```bash
npm run build
```
Builds the app for production to the `build` folder. It correctly bundles React in production mode and optimizes the build for the best performance.

---

## 📜 Available Scripts

- `npm start`: Starts the development server on port 3000.
- `npm run build`: Generates optimized static production assets in `/build`.
- `npm test`: Launches the interactive test runner.
